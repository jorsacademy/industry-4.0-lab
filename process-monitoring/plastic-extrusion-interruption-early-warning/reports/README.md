# Reports

Only aggregate analytical outputs are committed because the source data are distributed under CC BY-NC-ND 4.0.

Expected benchmark outputs:

- `source_summary.json` — source shape, sequence span and proxy counts;
- `model_selection.csv` — historical model/panel comparison;
- `metrics.json` — frozen calibration and final future-test result;
- `drift_diagnostics.csv` — aggregate selected-variable distribution shifts;
- `feature_importance.csv` — aggregate selected-model importance.

No row-level source reconstruction or prediction table is committed.
