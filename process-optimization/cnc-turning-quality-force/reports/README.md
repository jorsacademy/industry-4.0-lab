# Generated reports

The benchmark writes:

- `model_comparison.csv`: grouped-CV regression metrics by deployment mode/model;
- `metrics.json`: selected models and run-level evaluation summary;
- `oof_predictions.csv`: out-of-fold run-level predictions;
- `pareto_candidates.csv`: experimentally supported recipes with predicted quality/load and Pareto flag;
- `run_level_summary.csv`: one row per physical machining run;
- `feature_importance.csv`: selected-model feature importance/absolute coefficient tables.

Only reports generated from a verified source download should be treated as benchmark results.
