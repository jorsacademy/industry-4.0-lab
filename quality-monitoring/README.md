# Quality Monitoring

Smart-quality projects combine production context, traceability and inspection/test information to estimate quality risk without treating individual sensor rows as independent evidence.

## Projects

- [Electrical Test Report — Smart Quality Monitoring](electrical-test-report/) — real end-of-line test data.
- [Bosch Production Line — Early Defect Risk & Smart Quality](bosch-production-line/) — real large-scale production-line measurements.
- [SECOM Semiconductor Yield](secom-semiconductor-yield/) — real semiconductor process/sensor measurements.
- [Casting Quality Multimodal Prediction](casting-quality-multimodal-prediction/) — physics-informed synthetic prototype comparing process-only, inspection-only and multimodal defect prediction.
